# Telegram Channel Bot

Бот для автоматического создания, ведения и передачи приватных Telegram-каналов
с подключённых аккаунтов. Управление — только инлайн-кнопками.

> ⚠️ **Важно.** Массовое автоматическое создание каналов Telegram может расценить
> как спам. Задержки и прогрев снижают риск блокировки аккаунтов, но не убирают его
> полностью. Используй на свой риск.

---

## Что умеет

- **Аккаунты**: подключение по номеру/коду/2FA прямо в боте, прогрев сутки, статусы
  (прогрев/активен/пауза/флудвейт/заполнен/разлогинен/бан).
- **Автосоздание** приватных каналов по расписанию с суточным лимитом на аккаунт.
- **Ежедневные посты**: в каждый канал картинка «День N» + дата, случайное время
  внутри окна, ротация фонов и подписей.
- **Защита от флудвейтов**: очередь задач по аккаунтам, паузы 2–5 минут между
  действиями, сдвиг аккаунтов, авто-пауза после FloodWait (+час), стоп при спамблоке.
- **Дни и поиск**: распределение каналов по дням, поиск «сколько каналов на дне N».
- **Передача каналов**: подбор по дню → резерв + инвайт-ссылки → проверка вступления
  → передача владения (с 2FA) → выход старого аккаунта. История передач.
- **Статистика**: сводка, график роста, ежедневный отчёт владельцу, экспорт CSV.
- **Админ-панель**: роли owner/admin/user, выдача и отзыв доступа, журнал действий.
  Роль user — только просмотр (статистика, каналы, дни, история, предпросмотр картинки);
  управление аккаунтами, передачи, настройки и экстренный стоп — только owner/admin.
- **Надёжность**: WAL + очередь записи (без лагов), автопереподключение, повтор задач,
  автобэкап БД, graceful shutdown, healthcheck, всё состояние в БД.

## Установка

### 1. Получить ключи
- **BOT_TOKEN** — у [@BotFather](https://t.me/BotFather).
- **API_ID / API_HASH** — на https://my.telegram.org → API development tools.
- **OWNER_ID** — свой Telegram ID (бот покажет его при первом сообщении, либо см.
  [@userinfobot](https://t.me/userinfobot)).

### 2. Настроить .env
```bash
cp .env.example .env
```
Сгенерировать ключ шифрования:
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
Вставить его в `ENCRYPTION_KEY` и заполнить остальные поля.

> 🔑 **Не потеряй `ENCRYPTION_KEY`** — им зашифрованы сессии и пароли 2FA в БД.
> Без него после переустановки аккаунты придётся подключать заново.

### 3. Запуск через Docker (рекомендуется)
```bash
docker compose up -d --build
```
Логи:
```bash
docker compose logs -f
```

### 4. Запуск без Docker
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
export DATA_DIR=./data
python -m app.main
```

## Как пользоваться

1. Напиши боту `/start`. Владелец (OWNER_ID) получает доступ автоматически.
2. **👤 Аккаунты → ➕ Подключить** — введи номер, код (вводи с пробелами между
   цифрами!), при необходимости пароль 2FA.
3. Аккаунт уходит в **прогрев на сутки**, затем сам ставит 2FA (если её не было) и
   начинает создавать каналы и постить.
4. **📅 Дни / 🔍 Поиск** — смотри распределение каналов по дням.
5. **📤 Передать** — введи `ДЕНЬ КОЛИЧЕСТВО @username`, получи ссылки, дождись
   вступления получателя, нажми «Передать вступившие».
6. **⚙️ Настройки** — задержки, лимиты, окно постинга, 2FA, шаблоны, передача.
7. **🖼 Картинки** — загрузи фоны, настрой текст, посмотри предпросмотр.

Выдать доступ другому человеку: **🛡 Админ-панель → ➕ Выдать доступ**.

## Данные

Всё хранится в `DATA_DIR` (`/app/data` в контейнере, папка `./data` на хосте):
```
data/
├── bot.db            # база данных (SQLite, WAL)
├── sessions/         # (резерв) файлы сессий
├── backgrounds/      # загруженные фоны для картинок
├── fonts/            # свой шрифт (.ttf) — необязательно
├── logs/             # логи с ротацией
├── backups/          # автобэкапы БД (последние 7)
└── heartbeat         # для healthcheck
```

## Про передачу каналов

Telegram разрешает менять владельца канала только если у аккаунта:
- 2FA включена **не меньше 7 дней**;
- текущая сессия старше **24 часов**.

Поэтому бот ставит 2FA сразу после прогрева, а в карточке аккаунта показывает
«🔓 Можно передавать» только когда оба условия выполнены. До этого — дату готовности.
Передать канал можно лишь тому, кто уже вступил в него, — поэтому сначала выдаются
инвайт-ссылки, а передача идёт после проверки вступления.

---

## Лимиты Telegram (ориентир)

- ~500 каналов/групп на аккаунт (у Premium ~1000), дальше статус «заполнен».
- Публичных каналов (@username) — около 10, поэтому бот делает **приватные**.
- Точные лимиты Telegram не публикует и меняет; при частом создании возможны баны.

Первую неделю держи `daily_limit = 1–2` и следи за статусами аккаунтов.

## Структура кода

```
app/
├── main.py              # точка входа, запуск polling, startup/shutdown
├── config.py            # env + пути в DATA_DIR
├── settings.py          # настройки с кэшем и значениями по умолчанию
├── crypto.py            # шифрование сессий/паролей (Fernet)
├── utils.py             # время, день N, форматирование
├── logger.py            # логи с ротацией
├── notify.py            # уведомления владельцу
├── healthcheck.py       # проверка heartbeat для Docker
├── middlewares.py       # контроль доступа
├── keyboards.py         # инлайн-клавиатуры (2 столбца)
├── states.py            # FSM-состояния
├── db/
│   ├── database.py      # подключение, WAL, сериализация записи
│   ├── schema.sql       # схема таблиц + индексы
│   └── repo.py          # запросы
├── services/
│   ├── account_manager.py  # Telethon-клиенты, вход, 2FA
│   ├── task_queue.py       # очередь + защита от флудвейтов
│   ├── channel_creator.py  # создание каналов
│   ├── poster.py           # ежедневные посты
│   ├── image_gen.py        # генерация картинки «День N»
│   ├── transfer.py         # передача каналов
│   ├── stats.py            # статистика, график, дни
│   ├── backup.py           # бэкап БД
│   └── scheduler.py        # расписание задач
└── handlers/               # обработчики кнопок по разделам
```
